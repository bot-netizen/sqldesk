0.4: live dashboards and KPI tiles

In progress

Superset, Metabase and Grafana all have a gauge, a progress bar, a number with a trend, table formatting and goal lines. We had none of those five. They are also exactly what people put on a dashboard that refreshes every 30 seconds, so they arrive together with a way to run such a dashboard without every viewer re-running its queries.

Live dashboards

In progress

Mark a dashboard live and choose how often it updates: every 30 seconds, 1, 2 or 5 minutes. The server runs its queries once for everyone, and only while somebody has it open in a visible tab. Viewers just watch: no refresh button and no parameter changes, so nobody can multiply the load. People with permission can pause and resume it for everyone.

Turning a dashboard live needs its own permission, which admins can grant to a group. Viewing needs only normal dashboard access.

Calmer regular dashboards

In progress

Auto-refresh starts at 10 minutes, and it reuses a result that is already fresh enough instead of re-running every query from every open tab. The Refresh button skips anything that ran in the last minute.

Units, formats and thresholds

In progress

One place to set a value's unit, format, decimals, compact form (1.2k), min and max, and threshold colours, read by every visualization. Numbers are formatted by the browser's own Intl rather than an unmaintained library.

Why live dashboards work this way

Until now, auto-refresh re-ran every widget's query from every open browser tab. Ten people watching a twelve-widget dashboard every 30 seconds meant up to 240 query runs a minute against your database. A live dashboard runs those twelve queries once per interval, whoever is watching, and stops when nobody is.

Why Apache ECharts

Every chart type on this page is built into ECharts, under one API, one theme and one animation model. Its charts are plain JSON configuration, which is how SQLDesk already stores a visualization's settings. It animates from old values to new ones when data refreshes, and it can draw a chart on the server without a browser, which scheduled snapshots will need.

LicenceApache 2.0, and an Apache Software Foundation project, so no single company can re-license it.
In good companySuperset, Metabase, Evidence and Streamlit all ship ECharts 6.1.
CostOnly the chart types in use are bundled. The whole of 0.4 adds 28.5 KB, compressed.

Not everything is a chart. Tables, stat tiles and status grids are plain HTML, tiled maps stay on Leaflet, and pivot tables stay on react-pivottable.
