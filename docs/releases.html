One release, one idea.

SQLDesk is rebuilt a layer at a time. Each release has a single theme, and the theme is the point — a release that does a little of everything is a release nobody can describe. Below is every one of them, newest first, and the one being built now.

0.7.9 — Alerts that say how often, tables you can read

Shipped

28 October 2026

  • An alert remembers every time it fired, with the value the decision was made on, so one that went off six times before breakfast no longer looks like one that went off once. A Fires (24h) column on the list, the history beside the alert.
  • Slack templates are escaped for Slack rather than for HTML, so a value containing & arrives as &; the guide documents all twelve variables and the mrkdwn that differs from Markdown.
  • Table headers are marked by weight and a rule instead of a fill nobody could see — 1.10:1 against the rows it labelled — and the header text no longer fails AA at 3.33:1.
  • Data bars below zero had no colour at all: the default named a colour that does not exist, so the browser discarded it. Bars are solid now, with the number restated over the bar in an ink measured against the fill.
  • A line can say which line it is: six dash patterns per series, so this week and last week can share a colour.
  • Downloading a dashboard as an image no longer refuses at thirteen widgets. A picture has no pages; only the PDF does.
  • Avatars are drawn from initials on your own machines. Nothing is sent to gravatar.com, which previously learned the MD5 of every address in the organization on every page load.

0.7.8 — Second Look

Shipped

27 October 2026

  • Twelve things reported from using 0.7.7. Three turned out to be nothing — chart palettes were never removed, and there is no page-load regression — and saying so is part of the release.
  • Searching a list works. On queries and dashboards it is a box on the page rather than a dropdown called Filter; alerts has one at all; and on any list fetched whole it did nothing before this.
  • Numbers can be read by their value: one breakpoint colours a bar chart either side of it, and a table's data bars now point, taking a second colour below zero.
  • An agent can draw as well as read — a chart, a counter or a table on a draft query, and a draft dashboard to put them on. Fifteen MCP tools now, nine read-only.
  • A page that worked no longer reports a fault, a brand new install gets an answer from /api/config rather than a traceback, and schemas refresh every three hours instead of every thirty minutes.

0.7.7 — Scale, and a smaller image

Shipped

25 October 2026

  • The image is 1.22 GB, down from 1.59, built in two stages so the toolchain that compiles the drivers does not ship with them.
  • Work split across the processes that should do it: the web tier runs threaded with a statement timeout, scheduled queries and schema refreshes get their own workers, and Redis is given a memory ceiling instead of finding one.
  • A tag cannot publish an image whose tests were never run, and the chart is rendered three ways on every push.
  • Fixed: compiling a migration switched off the application's logging for the rest of the process, and two endpoints answered without the thing they were asked for.

0.7.6 — Avro and Protobuf on streams

Shipped

20 October 2026

  • A topic can be read as Avro or Protobuf, not only JSON — through a schema registry, which Confluent, Redpanda, Karapace and Apicurio all speak, or from an uploaded .avsc or .proto.
  • Fields arrive as real types: timestamps as timestamps, 64-bit integers as numbers, enums by name, nested messages as structs.
  • Decoding costs about 45,000 messages a second on one core, and JSON still costs nothing on the way in because it is never parsed there.
  • One migration, and every existing stream reads exactly as it did.

0.7.5 — One migration Job, not one per upgrade

Shipped

20 October 2026

  • Helm’s migration Job has a fixed name again, so an upgrade replaces the last one. A cluster upgraded 84 times had 79 Jobs and their pods still sitting in it.
  • The chart’s restricted pod security is tested rather than asserted: every container drops its privileges, every pod carries a seccomp profile, and each check fails when its rule is broken.
  • Under Argo CD, make the Secret once yourself. helm template cannot read back a generated one, so every sync would otherwise re-key every data source.

0.7.4 — Restricted clusters, and Kafka over TLS

Shipped

20 October 2026

  • The chart installs where Kubernetes enforces restricted pod security, with a production values file that matches.
  • Kafka over TLS with a CA, a client certificate and a key you provide.
  • Fixed: a verified dashboard cost a SQL statement per widget, a stream on a topic that was not there said nothing, and manage db current works again.

0.7.3 — Curating the catalog

Shipped

18 October 2026

  • The catalog can be searched, and told which tables to ignore.
  • An administrator can curate it over MCP — describe a table, hide one, propose a measure — and every write is audited with what it changed.
  • A dashboard can be verified, with a note saying what was checked. A badge with no reason is one nobody can weigh.
  • SQLDesk stops appearing in Kafka lag monitoring unless you ask it to.

0.7.2 — Smaller responses, honest types

Shipped

4 October 2026

  • Nothing compressed a response until now. A 6.7 MB result was 6.7 MB on the wire.
  • Every number and timestamp from DuckDB was declared a string, so charts had to guess. They are typed.
  • Eight data-source drivers upgraded, each checked against a real server rather than bumped and hoped for.

0.7.1 — Mimir, and connectors that tell the truth

Shipped

4 October 2026

  • Grafana Mimir, and a Prometheus runner that can carry a credential.
  • MySQL’s SSL Mode dropdown decided nothing at all; TLS is real now. Vertica is offered again.
  • Trino returns typed columns and the error the server actually sent, instead of the error handler’s own.

0.7.0 — Kafka Streams

Shipped

3 October 2026

  • A Kafka cluster is a data source and its topics are its tables. Analyse one before enabling it and you are told the columns, the rate, and how much history that buys.
  • A slot is a topic, not a viewer: five people watching orders share one consumer and one window between them.
  • Dashboard folders with a stated meaning, dashboards by email on a schedule, and OAuth 2.1 for MCP clients.
  • Permissions an administrator hands to a group, an admin section worth opening, and half the initial download — with nothing heavy on by default.

0.6.0 — MCP

Shipped

3 October 2026

  • An agent can reach SQLDesk over MCP, seeing no more than the editor gives it, and reading only.
  • A catalog built from what you already have, so an agent is given meaning rather than column names.
  • Measures are proposed, never assumed: a curator agrees one before it reaches anybody.
  • The semantic layer lives in git, uploads are confined to their own folder, and a security review covered everything reachable from outside.

0.5.0 — Interface

Shipped

24 September 2026

  • Dashboards stopped doing the same work several times over.
  • The chrome gave the charts their space back, and textboxes became somewhere to write.
  • Eight more chart types, and an Admin section.
  • Alerts can carry a picture, and a dashboard can go on a wall.
