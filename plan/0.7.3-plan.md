# SQLDesk 0.7.3 — scope agreed with Iqbal, 2026-10-18

Gap-closing on shipped features. Notebooks stay in 0.8, which is weeks away.

## Kafka consumers

**Why:** lag-monitoring scripts complain about SQLDesk. The stream consumer
calls `subscribe()`, which joins `sqldesk-stream-<id>` as a live member that
never commits, so a monitor sees a group with undefined lag. Analysis already
uses `assign()` and never commits, so it was never the culprit.

**Decided:**

- **Default: no consumer group the broker can see.** The client *requires* a
  `group.id` (tested: librdkafka refuses to construct without one), so the
  default is an id that never joins and never commits -- `assign()` at the
  chosen offset. One consumer per topic is already guaranteed by a Redis lock,
  so the group never balanced anything.
- **Optional consumer group name, per topic.** Set where a topic is analysed
  and enabled. People choose a prefix their monitoring ignores.
- **Save position: a checkbox, off by default.** Off says plainly that nothing
  is saved. On commits offsets, so a stream resumes where it stopped. Needs a
  name.
- **Start from: latest (default), earliest, or where it left off.** A setting
  on the topic, not a prompt: a stream starts when somebody opens a dashboard,
  and there is no moment to ask.

**Found while designing it:** consumption is a chain of jobs, and every job --
including each hand-over -- seeks to the end. So "earliest" applied naively
would replay the topic at every hand-over, and today each hand-over drops
whatever arrives between jobs. Positions are carried across the hand-over in
Redis, so the start setting applies only on a cold start.

## Catalog page

- **Search across every table, on the server.** The 200 cap is a server-side
  `.limit(200)`; tables past it were unreachable, not merely undisplayed.
- **Hide a table** (checkbox). Hidden tables disappear from the page **and from
  MCP** -- hundreds of Mimir metrics are noise to an agent too. Still
  queryable by name; hiding is not access control.
- **Toggle: show hidden tables.**
- **Toggle: only tables with a description.**
- **Placeholder in the description box** suggesting a format: grain, partition
  keys, key format.
- Column resizing was in the list but its sentence was cut off; Iqbal will
  raise it again if wanted.

## MCP

- **A tool to update a table's description and hidden flag.** The first MCP
  tool that writes. Administrators only. It will not overwrite a description a
  person wrote unless told to explicitly, and what it writes is marked as
  written through MCP.

## Dashboards

- **Verified by, with a description** of what was checked. Mirrors verified
  queries: who, when, a note.
